РЕЗУЛЬТАТ

east_recovered_centers.json и east_recovered_centers.csv содержат 112 кандидатов
на положения центров отражающих эллипсов, нормали, направления, ориентации полных
цилиндров и отдельные оценки согласованности с первичными измерениями.
Это данные для импорта/уточнения агентом, не файл нативной схемы приложения.
Кандидат нельзя автоматически активировать как метрологически подтверждённый.

Все 112 направленных оптических путей проверены трассировкой от источника через
общую оптику и реальные тела зеркал. Все 112 центров доступны внутри заданного
проектом пятна источника. Пересечений цилиндров не обнаружено. Минимальный зазор
между телами составляет 2,0004 мкм. Положительная проверка относится к заданным
размерам тел и текущей общей оптике, не к отсутствующим чертежам держателей.

13 сборок согласованы с первичной геодезией: 140 точек, RMS 0,65935 мм, максимум
2,03185 мм. Это остатки подгонки, не независимая точность восстановления.

Три сборки противоречат одновременному требованию согласования с первичной
геодезией и фиксированной текущей входящей оптикой:
  2.1: RMS 28,20359 мм;
  2.2: RMS 35,79987 мм;
  3.4: RMS 28,47698 мм.
Их координаты сохранены как условный кандидат в пределах текущего светового
пучка. Первичные измерения не исправлялись и не исключались из отчёта. Это не
основание объявить первичную геодезию ошибочной: требует разрешения противоречие
между данными и принятой оптической/механической моделью.

Общий RMS по 170 точкам полных лучей составляет 13,04765 мм, против 20,03803 мм
для исходных ручных линий. Уменьшение общего RMS скрывает важный компромисс:
сборки 2.3 и 2.4 исправлены к первичным измерениям, но 2.1 и 2.2 теперь расходятся
с измерениями, которые исходный ручной файл сохранял. Использовать только один
суммарный RMS для принятия кандидата нельзя.

СИСТЕМА КООРДИНАТ И НОМЕРА

Каноническая система — текущая survey/world проекта. В ней данный набор EAST
имеет отрицательные Z. Физическое название стороны хранится отдельно от знака Z.
Для каждой строки записаны center_survey_m и center_native_m, а также полная
матрица native_to_survey: p_survey = Q p_native + t.
Ошибка обратного перехода меньше 4e-16 м и характеризует вычисление, не точность.

Исходные source_id не переименованы. canonical_slot — геометрическое место в
упорядоченном веере. native_id использует текущий обратный порядок окон,
native_window = 5 - survey_window. Совпадение с номером физического изделия ещё
не подтверждено: physical_mirror_number_verified=false.

Принятая пользователем гипотеза для сборки 3.2:
  source 3.2.1 -> slot 1;
  source 3.2.2 -> slot 2;
  source 3.2.3 -> slot 3;
  source 3.2.4 -> slot 4;
  source 3.2.5 -> slot 6;
  source 3.2.6 -> slot 7;
  source 3.2.7 -> slot 5, восстановленный внутренний пропуск.
Старая линия source 3.2.7 сохранена в source_manual_points_survey_m, но её
направление исключено из априорной подгонки. В итоговой гипотезе центр этого
зеркала: (-0,461477043366; 1,180102937716; -0,679080528806) м в survey/world.
Новый native_id: 3_3_5. Направление: (0,712182588433; -0,701340055363;
0,030299958359). Исходная линия изменена на 538,829 мрад.

ЧТО ИМЕННО ВОССТАНВЛЕНО

Центр означает центр отражающего эллипса, не центр масс и не одну из двух точек
ручного файла. Ручные точки являются граничными точками луча в газовом объёме.
Для сравнения отдельно сохранён east_raw_manual_projected_centers.json:
это ближайшие точки исходных ручных прямых к оценкам центра соответствующих
первичных вееров. Они показывают вырожденность восстановления из одной прямой
и не являются уникальными физическими положениями зеркал.

МЕТОД

1. Первичный XLSX читается в неизменяемый ledger из числового XML. Ручные линии
   хранятся отдельно. Если есть две полные первичные точки, производная ручная
   линия повторно в likelihood или в угловой prior не включается.
2. По первичным направлениям оценивается эмпирический угловой шаблон семёрки
   после регистрации SO(3). Для каждой целевой сборки шаблон обучается по
   остальным 15 сборкам. Фиксированные 33 градуса не используются.
3. Пространственный prior получен из 16 полных ручных WEST-семёрок: удаляется
   общий перенос, система выравнивается по вееру, места сортируются по углу;
   используются медиана координат и наблюдаемый разброс. Это перенос слабой
   ручной механической информации между сторонами, а не независимая метрология.
4. Подбираются общий перенос, небольшие индивидуальные смещения, направления
   и повороты цилиндров вокруг нормалей. Условные масштабы: 1 мм на координату
   измеренной точки, индивидуальный сдвиг относительно семёрки не более 1,5 мм,
   поворот тела вокруг нормали не более 10 градусов. Это параметры сценария,
   а не установленные производственные или метрологические допуски.
5. Входящее направление получается из трассируемой общей оптики. Нормаль
   вычисляется из направлений входящего и отражённого лучей, с отражающей
   стороной d_in dot n < 0. Для тела используется собственная правильная
   матрица SO(3), обеспечивающая срез 45 градусов и апертуру 1 x sqrt(2) мм.
6. Ограничения источника учитывают его конечное пятно. Геометрические
   пересечения проверяются аналитическими опорными функциями и независимыми
   сертификатами GJK/общей внутренней области.
7. После первоначальной нелинейной подгонки выполнена консервативная коррекция
   положений при фиксированных нормалях и направлениях для зазоров и устранения
   затенений. Смена центра в этих шагах не делает первичную линию новой
   измеренной линией: итоговые остатки пересчитаны и сохранены.
8. Вся сцена с телами трассируется заново. Проверяется первое столкновение,
   отражение именно от покрытого среза и весь последующий путь луча.

Максимальное дополнительное перемещение при устранении пересечений — 74,8 мкм,
при устранении затенений — 0,4913 мм. Итоговые индивидуальные смещения в пределах
1,5 мм. Начальные solver_success=False в отдельных сборках относятся только к
стадии initial_nonlinear_pose_fit до этих коррекций. Итоговое состояние см.
final_validation и physics.full_optical_path.

МЕХАНИЧЕСКИЕ ОГРАНИЧЕНИЯ И НЕОПРЕДЕЛЁННОСТЬ

Длина 10 мм принята как полный осевой габарит скошенного тела; расстояние от
центра среза до заднего торца составляет 9,5 мм. Диаметр равен 1 мм. Если чертёж
определяет длину иначе, этот параметр нужно явно изменить и повторить проверки.
Боковая и задняя поверхности считаются непрозрачными поглощающими.

Полная геометрия реальных держателей, лазерных стержней и реальные точки
перетяжки не предоставлены. Статусы этих проверок — not_evaluated. Попадание
в пятно источника не доказывает нахождение внутри механического держателя.

Положение центра вдоль исходной прямой, поворот тела вокруг нормали и смещение
точки попадания внутри апертуры непосредственно этими данными не определяются.
Поэтому центр — условная регуляризованная оценка. В файле не выдуманы численные
метрологические доверительные интервалы. Неизвестные лучи остаются производными.

ВОСПРОИЗВЕДЕНИЕ

Нужен Python с зависимостями проверенного репозитория mirrormirror. Скрипты
принимают явные пути, не требуют путей исходного рабочего окружения:

python recover_east.py --repo PATH_TO_MIRRORMIRROR --input EAST_MANUAL_TXT
  --west-reference WEST_SPATIAL_REFERENCE_JSON --output OUTPUT_DIRECTORY

python repair_east.py --repo PATH_TO_MIRRORMIRROR
  --candidate OUTPUT_DIRECTORY/east_recovered_centers.json
  --output OUTPUT_DIRECTORY/east_clearance_repaired.json

python repair_east_paths.py --repo PATH_TO_MIRRORMIRROR
  --candidate OUTPUT_DIRECTORY/east_clearance_repaired.json
  --output OUTPUT_DIRECTORY/east_recovered_centers.json

Каждую команду следует записать одной строкой либо использовать синтаксис
продолжения строки своей оболочки. WEST_SPATIAL_REFERENCE_JSON — файл
west_reference_registration_hypotheses.json из предыдущего пакета проверки;
его контрольная сумма включена в spatial_prior. Он нужен для точного повторения
средней пространственной семёрки, не для переноса нормалей WEST в EAST.

В итоговый JSON встроены исходный primary_measurement_ledger, все исходные
двухточечные ручные линии, оптический snapshot и его hash. Текущий hash общей
оптики: 90949ea69c99672ab12debef811c0499d7fee50fd1fb21154a8818c51a20786c.

Для рабочего импортёра нужно отдельное представление ручных источников,
производных кандидатов и подтверждённых первичных наблюдений. Не копировать
mirrors или reference-линии в observations. Автоматическая активация данного
кандидата заблокирована из-за трёх конфликтующих сборок и неполных независимых
механических ограничений, хотя все 112 проверенных оптических путей допустимы.

ПОРЯДОК ЧЕТЫРЁХ ТОЧЕК ЭЛЛИПСА
ellipse_vertices_survey_m записаны циклически: +большая ось, +малая ось, -большая ось, -малая ось. Сторона покрытия задаётся normal_survey явно; обход точек её не определяет. При финальной упаковке исправлен только порядок экспорта, физические позы и трассировки не менялись.
