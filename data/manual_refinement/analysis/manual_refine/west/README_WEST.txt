WEST — исправленная ручная геометрия для интеграции в mirrormirror
Проверенный код: 4ab80dfba048e11cf5a3b0bef7dc6832b298540b

Главный файл: west_manual_corrected_survey.json.
Это вход для нового импортёра ручной реконструкции, а не файл существующей
схемы mirrorlab.physical-configuration и не готовая активируемая конфигурация.

КООРДИНАТЫ
Каноническая система — survey/world текущего проекта, то есть исходная XYZ
геодезии. Все координаты в метрах. Для этой таблицы WEST численные Z
положительны: приблизительно +0,344…+1,338 м. Физическое обозначение WEST/«−»
не использовано для принудительной смены знака координаты.
Порядок четырёх точек сохранён от источника. Отражающую сторону нельзя
восстанавливать по обходу точек: отражающее преобразование меняет ориентацию
обхода; используйте явно сохранённую физическую нормаль.

Исправление исходных точек:
1. Удалены четыре точно установленных переноса стержней из приложенного TXT.
2. Применена выбранная историческая жёсткая привязка к геодезии.
3. Все 112 исходных идентификаторов сохранены. Геометрические соответствия 83
   полностью измеренным лучам даны отдельно; остальные соответствия — null.

survey_center_m и survey_edge_points_as_transformed_m — неизменяемый результат
этого преобразования. Это главные поля ручной координатной реконструкции.
native_center_m — обратный перенос через закреплённый current display_frame.
Исходному окну w соответствует native-окно 5−w. Номер зеркала в native_stable_seed_id
служит только стабильным идентификатором; физическое совпадение индексов не
предполагается. При смене display_frame native-координаты пересчитываются.

ПЛОСКОСТИ
survey_original_plane_normal — перенесённая плоскость исходного ручного файла.
Она была получена с противоположным соглашением о падающей ветви. Её нельзя
использовать как сильный приор физической ориентации в текущем оптическом пути.
Изменение нормали относительно неё — восстановление оптического соглашения,
а не малая физическая переюстировка изделия.

survey_repaired_45deg_ellipse_in_original_plane_m — отдельная коррекция размеров
эллипса в той же исходной плоскости. Она не исправляет падающую ветвь.

operational_optical_seed — физическая нормаль, рассчитанная из текущей общей
оптики и желаемой направленной линии. При неизменённой текущей оптике 112
центров дают 72 доступных входящих луча и 40 выходов за пучок. Эти 40 записей не
считаются освещёнными; сохранённое направление для них условно.

recommended_optimization_seed — отдельный кандидат с малой поправкой нормалей
MC1…MC4, последующей подстройкой ненаблюдаемого вращения тел и небольшим
перемещением центров вдоль фиксированных выходящих прямых. Он не заменяет
неизменяемые survey_center_m. Поправки положения сохранены явно.
Исходящие траектории и первичные точки при этом не сдвигались.

ТЕЛА
Цилиндр D=1 мм, полный осевой габарит 10 мм, срез 45°. Рабочая конвенция длины:
от минимального Z среза до заднего торца. Она требует сверки с чертежом.
Все body_native.rotation и body_survey.rotation принадлежат SO(3).
Для отражающей преобразовательной матрицы current frame det(Q)=−1 использована
симметрия цилиндра относительно локальной Y, а не некорректное умножение
матрицы собственной ориентации на отражение.

СТАТУС ПОСЛЕ ПОЛНОЙ ПРОВЕРКИ
Для варианта с сохранением выходящих прямых и малыми смещениями центров
максимальная поправка положения равна 39,731 мкм, вращение вокруг нормали
не превышает 1,272°. Пересечений тел нет. Все 112 входящих лучей достигают
своих площадок и правильно отражаются, однако только 77 выходящих путей
не перекрыты; 35 перекрываются соседними цилиндрами.

Отдельный alternative_exit_refinement_seed дополнительно перемещает центры
по Z до 0,461 мм при сохранении среднего Z семёрки. Число неперекрытых путей
увеличивается до 85, остаются 27 перекрытий. Пересечений тел нет. RMS по
166 использованным геодезическим точкам меняется с 1,616 до 1,605 мм.
Это альтернативное частичное уточнение, не замена исходных ручных координат
и не доказательство полной физической допустимости.

Отсутствие пересечений тел не означает отсутствия перекрытий отражённых лучей.
Полный путь каждого луча, держатель и сторона перетяжки проверяются отдельно.
Пока отсутствуют независимо заданные границы держателя и точки перетяжки,
никакой кандидат не должен автоматически получать статус полностью допустимого.
Средние точки отдельных ручных сборок отстоят от соответствующих текущих
идеальных опорных точек до 20,826 мм. Это сохраняется как нерешённая задача
механической привязки; наличие исправленных мировых координат не доказывает
попадания внутрь неизвестного держателя.

ВОСПРОИЗВЕДЕНИЕ
1. build_west_corrected.py --repo MIRRORMIRROR --input SOURCE.txt
   --reference west_historical_registration_reference.json --out DIRECTORY
2. apply_mc_candidate.py --repo MIRRORMIRROR --input DIRECTORY/west_manual_corrected_survey.json
   --optical-candidate west_mc_steering_candidate.json --out DIRECTORY
3. refine_west_bodies.py --repo MIRRORMIRROR --input DIRECTORY/west_manual_corrected_survey.json
   --out DIRECTORY
4. finalize_west_validation.py --input DIRECTORY/west_manual_corrected_survey.json
   --full-trace-report west_mc_slide_roll_full_reflections.json --out DIRECTORY
5. attach_west_exit_variant.py --repo MIRRORMIRROR --input DIRECTORY/west_manual_corrected_survey.json
   --candidate-bodies west_exit_z_candidate_bodies_native.json
   --full-trace-report west_exit_z_full_reflections.json
   --residual-report west_exit_z_primary_residuals.json --out DIRECTORY

Шаг 1 воспроизводит только координатную коррекцию и базовую оптическую гипотезу.
Шаги 2–3 добавляют условный кандидат для последующей оптимизации и проверки.
Вспомогательный historical reference содержит выбранную регистрацию и 83
соответствия; её невязка 1,616 мм по использованным измерениям не является
независимой точностью восстановления недостающих лучей.
