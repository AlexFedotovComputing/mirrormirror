1. Canonical coordinates
Use the existing raw survey/world coordinates and metres as canonical import coordinates. In these actual files WEST injection has positive z, EAST negative z. Physical labels EAST/WEST, source side, ring side and injection side must be separate explicit metadata; never infer them from sign(z), archive signs or route filenames. The static current frames put source/ring opposite injection and are retained unchanged in this package. For an active saved configuration use its own embedded display_frame, not a newly refitted static frame.

2. Exact geometry vs optical interpretation
WEST: undo the four documented source-sector shifts, use the fitted historical registration only for the manual reconstruction (centres, original four points, reconstructed outgoing lines). It is not a valid transformation of the whole optical instrument: applying the historical +Z frame to the archived source/ring would put them on the same half as the injection mirrors. Historical normal is retained as provenance. The operational normal is re-derived from the chosen, fully traced current incident branch and the preserved directed target ray: n=normalize(d_out-d_in), with d_in dot n<0. A near90degree change relative to the simply transformed historical plane is a conversion of inconsistent optical conventions; it must not be represented as a measured physical adjustment or subjected to a tiny incremental-rotation prior about that historical normal. Apply incremental normal priors after this semantic conversion.

EAST: the manual two-point lines are already in canonical survey coordinates. P2->P1 gives the directed propagation into the volume. P1/P2 are export clipping points, not cut centres. Keep line plus centre/longitudinal prior separate. Accepted3.2 hypothesis: source measured IDs1..6 occupy angular slots1,2,3,4,6,7; the inferredmissingray belongs in slot5. This does not rename primary observation IDs.

3. Native integration
p_native = Q^T(p_survey-t), d_native = Q^T d_survey. Current WEST Q has det=-1, which is a coordinate-basis parity, not an allowed physical SO(3) pose. For cut-cylinder body rotations, reconstruct the proper pose from axis/normal in each frame or use R_survey=Q R_native diag(1,-1,1). The localYreflection leaves the circular cylinder and x=z cut invariant and preserves the localcutnormal. Do not store an improper matrix as a physical rotation. Polygon winding must also be checked after parity changes. Native window index is5-surveywindow in these pinned current frames; physical mirror numbering remains a separate mapping.
